## 先搞清楚 Instagram 到底允许多少个号

两个数字经常被混着说，其实说的不是一件事。

自己动手加号，官方路径是这样的：

1. 打开 Instagram，点右下角的「个人资料」或头像

4. 点「创建新账号」，输入新用户名，点「下一步」

### 三个多数教程不讲的细节

**子账号会通过「推荐用户」被推给粉丝。** Feed 和 Story 之间插进来的「推荐用户」栏，可能把你自己的小号显示出来，粉丝或第三方点进主页就发现了。做矩阵、做水下号的时候，这条比 IP 问题更容易翻车。

**「从列表移除」不等于注销账号。** 在账号列表里删掉一个子号，实际只是解除和主号的绑定、再删掉本机的登录资料，账号本身还活着。要它彻底消失得走注销流程。删错了也不至于报废，用「添加 Instagram 账号」重新登录就能恢复。
